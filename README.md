# QR赤線エラー！黒服から逃げ切れ

デジチケの発券エラーで黒服にマークされた——!? 指1本で遊べるカジュアル・ステルスゲーム。

**遊ぶ → https://7ckwhjy67f-stack.github.io/ticket-error-escape/**

## 遊び方

1. スマホ風デジチケ画面で「発券機にかざす！」をタップ
2. 🔴 発券エラー発生 → 黒服が登場、逃走スタート
3. **画面を長押し（PCは Space / マウス押下）** で出口へダッシュ
4. **指を離す**と立ち止まって「スマホをいじる通行人」のフリ → 黒服の赤い視界に入っていても見逃してもらえる
5. 黒服の「?」（振り向きの予兆）を見たらすぐ離す。視界の中で動くと即・本人確認行き
6. 30秒以内に出口（改札方面）まで逃げ切ればクリア
7. リザルトの「もう一度挑戦」でデジチケ画面に戻る

## 結果

- クリアタイムで **SS / S / A / B / C**、黒服につかまった・時間切れは **D** のランク判定
- タイムと突破率から称号も決定（「名義守り抜き神」「ギリギリ現場生還」「本人確認窓口連行」「誓約書ルート」など）
- 「もう一度挑戦」でデジチケ画面（QRをかざすところ）に戻って最初から
- 「結果をXでシェア」ボタンでランク・タイム入りのポスト画面を開けます（ゲームURL付き）

### ランク基準

| ランク | 条件 |
| --- | --- |
| SS | 21.0秒以内にクリア |
| S | 23.0秒以内 |
| A | 25.5秒以内 |
| B | 28.0秒以内 |
| C | 30.0秒以内（クリア） |
| D | 黒服に確保／時間切れ |

## 技術

- HTML / CSS / JavaScript の単一ファイル（`index.html`）。外部ライブラリなし
- Canvas 2D 描画、効果音は Web Audio API で合成（ミュートボタンあり）
- スマホ縦画面ファースト（tap / long press のみ、スクロール・拡大なし）

※ 登場する「本人確認」「名義」などはすべてフィクションの演出です。
